# T3-REVIEW.md — independent code review of the T3 engine changes (15 Nov, ~08:35)

Scope: `git diff t2-freeze -- mesh/brain.py mesh/simgen.py mesh/simworker.py mesh/feedback.py`, at `t3/library` d9504cf.
Method: zero spend; `Brain.on_turn` driven over real round-robin observations for the known simulators with the model
stubbed (~610 turns, 11 games), plus targeted scripts. No crash and no illegal final move in normal turns.
Findings most severe first. **Status column is kept up to date by whoever fixes them.** Findings that also exist in
candidate A (`t3/candidate`) are marked A.

| 1 | can lose a game | brain.on_turn (warning block, candidates) | After a warning on an engine move from a known/verified simulator the engine stays on but the rejected move is not removed from the candidates: the deterministic policy returns it again; the shell's gate then swaps in a random example (Hex: an occupied cell -> second illegal move, game lost). | 3 | library policy silently off | simgen.install_known / known/mini_poker.py | Only sim.py is copied to /memory; the poker strategy JSON is loaded relative to `__file__`, so at play time the table is empty and `recommend` returns [] (plain MCTS plays).
